# DonApp - Software Specification

## Descripción

Este directorio contiene toda la documentación funcional y técnica del proyecto DonApp.

El objetivo es definir las funcionalidades, reglas de negocio, arquitectura, tecnologías y planificación antes de desarrollar cada módulo de la aplicación.

Toda modificación importante del proyecto deberá documentarse previamente en esta carpeta.

---

## Organización

spec/

├── README.md

├── constitution/

│   ├── mission.md

│   ├── tech-stack.md

└── features/

---

## Constitución

La carpeta constitution contiene los principios fundamentales del proyecto.

- mission.md
  Define la misión, visión y objetivos de DonApp.

- tech-stack.md
  Describe las tecnologías, herramientas y convenciones utilizadas durante el desarrollo.

- roadmap.md
  Contiene la planificación general del proyecto.

---

## Features

Cada funcionalidad tendrá su propia carpeta.

Cada feature estará formada por tres documentos:

spec.md

Describe el comportamiento esperado.

plan.md

Explica cómo será implementada técnicamente.

tasks.md

Lista las tareas necesarias para completar la funcionalidad.

---

## Metodología de desarrollo

El desarrollo seguirá el siguiente flujo:

1. Definir la funcionalidad.
2. Elaborar el SPEC.
3. Diseñar el plan de implementación.
4. Crear las tareas.
5. Implementar el código.
6. Realizar pruebas.
7. Actualizar la documentación.
