# DonApp

DonApp es una aplicación móvil orientada a facilitar la publicación y solicitud de donaciones entre personas de una misma ciudad.

El backend utiliza Next.js con Pages Router, TypeScript, Prisma ORM y PostgreSQL. El cliente móvil con Flutter y Dart se desarrollará posteriormente.

El diseño funcional y técnico específico de cada módulo se encuentra en `spec/features/`. Cada feature dispone de su especificación, plan de implementación y registro de tareas.

La implementación del backend se realizará progresivamente de acuerdo con `spec/constitution/roadmap.md`. La documentación aprobada puede describir funcionalidades que todavía no están implementadas.
